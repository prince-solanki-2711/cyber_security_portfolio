## What I Document

The individual lab README files are written in simple language and are intended to help me revise the topics. Depending on the room, they may include:

- A short overview of the room
- The main concepts and topics covered
- Simplified notes from the learning material
- Key points I learned from the exercises
- A completion screenshot, where available

## How to Explore

1. Choose a learning path from the folders above.
2. Open its README for an overview, if available.
3. Open an individual lab folder to read the notes for that room.
4. Check the `screenshot/` folder inside a lab when you want to see its completion proof, if one is included.
